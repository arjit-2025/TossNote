Notes created in this browser

    Live edits

    Edit a note after you share it, and anyone viewing it sees the change right away.

    Private by choice

    Turn on passwords, burn after reading, view limits or real end-to-end encryption.

    Files too

    Attach images, PDFs, videos or anything else. The server sets the only size limit.

    From the terminal

    curl --data-binary @notes.txt "/api/raw?expiry=1d"
echo "secret" | curl --data-binary @- "/api/raw?burn=1"
curl "/r/NOTE_ID"

    Query options: expiry (10m, 2h, 3d, 1w, 1y, never), burn=1, views=N, syntax, title, slug. Send a password with the X-Password header. The response's X-Edit-Token header holds the edit token.
